1. Recruit BDRs (largely female) and track them in the ops sheet.
2. Get each BDR **Set Up**: LinkedIn URL captured, account **Verified**, connected to zevari.ai, **Zevari Active**.
3. BDRs run LinkedIn outreach via Zevari; prospects book calls.
4. Joseph closes the client on Zevari.ai and earns a **VAR cut**.
5. Upsell **managed BDR services**: hire/manage more BDRs for that client using the same recruit → connect → Zevari loop (positive feedback loop).
