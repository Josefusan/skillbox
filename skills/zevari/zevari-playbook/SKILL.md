# Zevari playbook (VAR + managed BDR)

## Loop

1. **Recruit** BDRs (largely female) and log them in the ops sheet `CTV BDR Zevari BDR girlies`.
2. **Set Up** each BDR: capture LinkedIn URL, mark Verified, connect account to zevari.ai, mark Zevari Active.
3. **Outreach**: BDRs run LinkedIn outreach through Zevari; prospects book calls.
4. **Close**: Joseph closes the client on Zevari.ai and earns a VAR cut from Zevari.
5. **Upsell managed services**: hire/manage additional BDRs for that client with the same recruit → connect → Zevari loop.

This creates a **positive feedback loop**: more clients → more managed BDRs → more Zevari seats/activity → more closes.

## Roles

- **Joseph**: closer; final approver on commercial terms; VAR recipient.
- **BDRs**: LinkedIn outreach operators hooked to Zevari.
- **Zevari Chief of Staff**: owns the sheet, Set Up throughput, and pipeline hygiene.
