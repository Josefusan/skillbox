# Zevari BDR pipeline

## Stages

1. **Recruit / log** — add Name; set BDR to `Pending` or `Yes`.
2. **Set Up** — collect Linkedin URL; complete product Set Up; flip Set Up off `Not Yet` when done.
3. **Verified** — mark Verified `Yes` when the account checks out.
4. **Zevari Active** — confirm connected to zevari.ai and actively usable for outreach.
5. **Costed** — fill weekly/monthly BDR cost, Zevari seat cost, Total (only with confirmed numbers).

## Handling by BDR status

- **Yes**: highest priority. Push Set Up + LinkedIn + Active before anything else.
- **Pending**: keep warm; do not block Yes throughput.
- **DQ**: leave marked DQ. If a comment notes upside (e.g. referrals), surface it to Joseph — do not silently drop.

## Success signal for a BDR row

Linkedin URL present, Verified = Yes, Zevari Active set, Set Up complete, costs filled only when known.
